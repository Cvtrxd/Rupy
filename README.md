# 🚀 Язык программирования Rupy

**Rupy** — это интерпретируемый язык программирования с понятным русскоязычным синтаксисом. 

Проект разработан для того, чтобы сделать написание кода простым и доступным, а также предоставить удобную интеграцию с операционной системой Windows.

---

## ✨ Особенности

* 🔤 **Русскоязычный синтаксис** — пишите команды на русском языке.
* 📦 **Легкая установка** — полноценный инсталлятор, который сам настраивает систему.
* 🔗 **Интеграция с Windows** — файлы расширения `.rupy` получают собственную иконку и запускаются по двойному клику.

---

## 🛠️ Установка

1. Перейдите в раздел [Releases](../../releases) на странице репозитория.
2. Скачайте последнюю версию инсталлятора `RupySetup.exe`.
3. Запустите файл и следуйте инструкциям мастера установки.
4. После завершения установки файлы с расширением `.rupy` будут автоматически запускаться через интерпретатор Rupy!
