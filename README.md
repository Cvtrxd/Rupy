# Rupy (Рупи)
# 🚀 Язык программирования Rupy

**Rupy** — это интерпретируемый язык программирования полностью основанный на Python с понятным русскоязычным синтаксисом. 

Проект разработан для того, чтобы сделать написание кода простым и доступным, а также предоставить удобную интеграцию с операционной системой Windows.

---

## ✨ Особенности

* 🔤 **Русскоязычный синтаксис** — пишите команды на русском языке.
* 📦 **Легкая установка** — полноценный инсталлятор, который сам настраивает систему.
* 🔗 **Интеграция с Windows** — файлы расширения `.rupy` получают собственную иконку и запускаются по двойному клику.

---

## 🛠️ Установка

1. Перейдите в раздел [Releases](../../releases) на странице репозитория.
2. Скачайте последнюю версию инсталлятора `RupySetup.exe`.
3. Запустите файл и следуйте инструкциям мастера установки.
4. После завершения установки файлы с расширением `.rupy` будут автоматически запускаться через интерпретатор Rupy!

## 🔌 Настройка в Visual Studio Code

* Для комфортной разработки вы можете установить официальное расширение **Rupy** прямо из VS Code:

1. Откройте VS Code.
2. Перейдите во вкладку **Расширения** (`Ctrl + Shift + X`).
3. Введите в поиске **Rupy**.
4. Нажмите **Установить**.

 Расширение обеспечивает подсветку синтаксиса для файлов `.rupy`

* Что бы запускать код по кнопке прямо в Visual Studio Code нужно:
1. Открыть VS Code.
2. Перейти во вкладку **Расширения** (`Ctrl + Shift + X`).
3. Ввести в поиске **Code Runner**.
4. Нажать **Установить**.
5. Нажать сочетание клавиш (`Ctrl + Shift + P`)
6. Вписать в строку: Открыть пользовательские настройки (JSON)
7. В открывшемся файле settings.json замените всё на:
```rupy
{
  "explorer.confirmDelete": false,
  "security.workspace.trust.untrustedFiles": "open",
  "liveServer.settings.donotShowInfoMsg": true,
  "code-runner.runInTerminal": true,
  "code-runner.executorMap": {
    "javascript": "node",
    "python": "python -u",
    "rupy": "rupy"
  }
}
```
